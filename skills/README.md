# Skills

Reusable know-how from building Evens, written so a new app can start from it. Each folder has a `SKILL.md`.

| Skill | Use it when |
|---|---|
| `github-pages-data-pipeline` | An app needs fresh data but should have no server: scheduled GitHub Action → JSON → static site |
| `free-api-budgeting` | You're about to depend on a metered or rate-limited API |
| `phone-first-pwa` | Building an installable phone web app (safe areas, offline, sound, gestures) |
| `validate-model-before-trusting` | A model's numbers will be shown to the user |

Only things actually learned in this repo are recorded here. Add to a skill when a new project teaches something; don't pad.
